## Ten lines to your first transcript

```dart
final models = await ModelManager.open();
final model = await models.ensure(const ModelId('parakeet-tdt_ctc-110m-Q4_K_M'));

final session = await TranscribeSession.open(model);
session.text.addListener(() => print(session.text.value.full));

await session.start(); // asks for the microphone, then listens
// ...the user speaks...
await session.stop();
```

## Built on transcribe.cpp

The speech recognition itself is
[transcribe.cpp](https://github.com/handy-computer/transcribe.cpp), a fast
C/C++ engine for many speech models. transcribe_cpp brings it to Flutter and
adds what an app needs around it: microphone capture that survives calls and
route changes, voice detection, sentence splitting, live text, and model
downloads. See the [acknowledgements](reference/acknowledgements/) for
everyone whose work this builds on.
